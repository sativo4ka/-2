Вариант 1. Playlist (плейлист)

Класс Playlist хранит список названий треков.

void Add(string title) — добавляет трек в конец списка.Индексатор this[int position] — доступен на чтение и запись, возвращает/задаёт название трека по позиции. Бросает ArgumentOutOfRangeException, если позиция выходит за пределы списка.Индексатор this[string title] — только на чтение, возвращает позицию трека с таким названием или -1, если трек не найден.Переопределите ToString(), чтобы вывести треки через запятую с указанием их позиций, например: "0: Track A, 1: Track B".
